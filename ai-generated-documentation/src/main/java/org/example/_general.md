## General Documentation for example package

This documentation provides a comprehensive overview of the `example` package, detailing its functionalities, usage instructions, and best practices. The package encompasses various Java programs designed to illustrate fundamental programming concepts and algorithms.

- [FizzBuzz.md](FizzBuzz.md)
  - **Description:** This program implements the classic FizzBuzz challenge, printing "Fizz" for multiples of 3, "Buzz" for multiples of 5, and "FizzBuzz" for multiples of both. It showcases conditional statements and iteration control.
